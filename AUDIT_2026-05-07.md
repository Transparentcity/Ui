## 1. Security

### P0 (exploitable now)

- [src/app/api/generate-emails/route.ts:328] No auth, no rate limit. Anyone can drive Anthropic spend (8000 maxTokens/call) and read arbitrary `prospects` rows by guessing UUIDs. Fix: `requireAdmin`, scope query by org, IP rate limit.
- [src/app/api/analyze-anomaly/route.ts:720] No auth, no rate limit. Direct Anthropic-bill DoS. Fix: session check + per-IP rate limit + cap input size.
- [src/app/api/research-media/route.ts:67] SSRF. `path` query passes through `new URL(permalinkPath, upstreamBase)`; absolute URL in `permalinkPath` overrides the base, server fetches arbitrary host (incl. `169.254.169.254`). Fix: reject if `permalinkPath` parses as absolute, or assert `.origin === upstreamBase.origin` post-resolve.
- [src/app/c/[slug]/newsletter/[date]/page.tsx:185] `dangerouslySetInnerHTML` on backend `body_html` with no sanitizer. Public route. Stored XSS surface if any LLM-generated piece pulls untrusted text. Fix: DOMPurify.sanitize server-side.
- [src/components/NewsletterAdmin.tsx:2627, 2777, 2000] `final_report_html` and `testResult` rendered raw. Admin context but admin-XSS pivots to admin token theft.

### P1 (likely problem)

- [next.config.ts:64-72] Catch-all `/api/:path*` proxy exposes the entire Python backend (incl. `/api/admin/*`) to the public internet. Verify backend gates every admin route. Add a Next middleware deny for `/api/admin/*` and `/api/internal/*`.
- [src/app/api/welcome-email/route.ts:198] and [src/app/api/city-suggestion/route.ts:48] Origin allowlist uses `origin.includes(".vercel.app")`. Free preview deploys bypass it. Fix: exact match to configured site origin + a specific known preview host.
- [src/components/PageFeedback.tsx:55] No client-side captcha; relies entirely on backend rate limit. Confirm backend has IP rate limit + length cap. Add hCaptcha or proof-of-work.
- [src/components/FeedAdmin.tsx:798] `previewStory.article_html` rendered raw. Sanitize.
- [src/app/chat/[hash]/page.tsx:135] LLM content piped through `.replace(/\n/g,"<br/>")` and injected raw. Escape HTML first or render via sanitized markdown.
- [next.config.ts:50-62] `remotePatterns` open to `http,**` and `https,**`. `/_next/image?url=...` becomes an open image proxy and a probe-internal-IP vector. Lock to your real domains (transparent.city, your CDN, Mapbox).
- No security headers anywhere (no `vercel.json` headers, no `next.config.ts` `headers()`, no middleware). Add CSP, `X-Frame-Options: DENY`, HSTS, `Referrer-Policy: strict-origin-when-cross-origin`.

### P2 (hardening)

- [src/app/api/cities/[city_id]/structure/route.ts:51-72] Forwards client `Authorization` then echoes upstream error body to client (`details: lastError`). Strip auth from echoed errors.
- [src/app/api/cityreadiness/force-match/route.ts:32] `requireAdmin` ok; add string/length validation on `cityId/metricKey/datasetId` written to disk.
- [src/app/api/welcome-email/route.ts:269] Verify `sendEmail` strips `\r\n` from `subject` (header injection via `cityName`).
- [next.config.ts:11-37] `mergeSendgridFromPlatformEnvDir` reads arbitrary `.env` from a path in env var. Restrict to non-production or a hardcoded path.
- [src/components/PageFeedback.tsx:23] storage key includes raw `pageUrl` (UTM-sensitive). Normalize.
- No CSRF protection. SPA-style Bearer auth means most routes are fine, but `/api/welcome-email` and `/api/city-suggestion` rely on Origin/Referer (acceptable for browser-only, fragile if anyone adds cookie auth).

## 4. Accessibility and edge-case UX

### P0

- Hand-rolled modal overlays missing `role="dialog"`, `aria-modal`, focus trap, Escape, focus-return-to-trigger:
  [src/components/RenameDialog.tsx], [src/components/UserMetricOrderDialog.tsx], [src/components/MobileMoreMenu.tsx], [src/components/EditHomeLocationModal.tsx]. Either port to Radix `Dialog` or add the ARIA + focus trap by hand.
- [src/app/error.tsx:79], [src/app/not-found.tsx:34] Decorative emoji read aloud as "warning warning". Wrap with `aria-hidden="true"`. Add `role="alert"` to outer card.
- [src/components/PageFeedback.tsx:284-302, 434-449] `<input>` and textarea use placeholder only; no `<label>` or `aria-label`. The widget also has no `<form>` wrapper, so Enter doesn't submit.
- [src/components/ui/dialog.tsx] Many `DialogContent` callers omit `DialogTitle` (Radix dev warning + a11y fail). Audit usages.
- No skip-to-content link in root layout. Add `<a href="#main" class="sr-only focus:not-sr-only">` and `<main id="main">`.
- `loading.tsx` files render plain spinners with no `role="status"` or `<span class="sr-only">Loading…</span>`. AT users hear silence.

### P1

- 39+ files use `text-gray-400 / zinc-400 / slate-400` on white (~3.4:1, fails AA 4.5:1 for body). Spot-check `MetricDetailContent.tsx`, `feed/*`, `crm-sidebar.tsx`. Bump to `text-gray-500`.
- Search/filter inputs with placeholder but no label/aria-label: [TopNavCitySearch.tsx:247], [UserManagement.tsx:747], [JobListPanel.tsx:438], [NewsletterAdminSubscribersTab.tsx:438], [schema-match-content.tsx:831], [forensics-overview-page.tsx:116], [forensics-findings-page.tsx:108], [LocationMapSave.tsx:206], [ResearchView.tsx:534].
- [src/components/PageFeedback.tsx:96-99] Animation not gated by `prefers-reduced-motion`. Only 4 CSS modules respect that media query.
- Only 5 files use `AbortController`. Long-tail backend hangs leave UIs stuck on spinners. Wrap critical fetches with a 20s timeout + retry.
- Print stylesheet missing. Newsletter archive pages will be printed; add `@media print` to hide nav, sidebar, feedback widget.
- `robots.ts` `noindex`s admin-ish routes (`/applause`, `/signals`, `/flags`, `/research-queue`, `/cityreadiness`, `/feed-preview`, `/anomalies`, `/debug`) but they're still client-side reachable. Add server-side gating in middleware.

### P2

- Long content overflow in flex children without `min-w-0` (story cards in `feed/*`, `MetricDetailContent.tsx`).
- Possibly orphaned routes (no nav links found): `/applause`, `/signals`, `/flags`, `/cityreadiness`, `/research-queue`, `/feed-preview`, `/anomalies`, `/analytics`, `/debug/health`, `/data`, `/maps`, `/media`, `/create-emails`, `/message-review`. Either gate behind admin nav or remove.
- Tooltip-on-hover only on sparklines / charts (verify focus + tap reveal).
- [src/components/PageFeedback.tsx:23] Storage key uses raw `pageUrl` with UTM params; same page recounts as new.
- Empty states minimal ("No jobs found"); verify dashboards handle 0-story friendly.
- No service worker / offline banner. Add `navigator.onLine` listener.
- `loading.tsx` spinners cause CLS; replace with skeletons matching real card sizes.
- Only 4 CSS modules ship `:focus-visible`. Add a global `:focus-visible { outline: 2px solid var(--brand-primary); outline-offset: 2px; }` in `globals.css`.
